Assignments

Each task builds on the one before it, so complete them in order.

  1. Task 01, Media and Page Sections: build a course page.
  2. Task 02, Tables and Better Forms: build an intern registration page.
  3. Task 03, HTML Basics and Forms: build a personal profile and contact page.
  4. Task 04, Advanced Form and Content Tags: build an application portal.
  5. Task 05, Final Website: combine everything into one website.
